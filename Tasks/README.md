# Tasks

このディレクトリは、TODO と Issue から参照する具体的な実施内容を管理します。

## Rules

- 1 Task につき 1 Markdown ファイルを作成します。
- `Status`、`Priority`、`Phase`、`QCDS`、`Acceptance Criteria`、`Validation` を記録します。
- `TODO.md` と `Issues/*.md` から Markdown link で参照します。
- GitHub Issues 取込で作成した Task は `GitHub Issue:` に元 issue の個別リンクを記録します。
- 完了済み Task も、QCDS と traceability の証跡として残します。
